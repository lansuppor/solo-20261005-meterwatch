# meterwatch

建筑能耗监测与告警：本地累计电表读数导入与消耗核查。

需要 Node.js 24，无外部运行依赖。

## 用法

```sh
node app.ts                       # 显示帮助
node app.ts --help | -h           # 显示帮助
node app.ts import <file.csv>     # 导入 CSV 读数（整批成功或整批拒绝）
node app.ts readings [筛选...]    # 查询读数、区间与消耗
```

不支持的参数返回退出码 2；数据/运行错误返回退出码 1。

## CSV 格式

表头固定为：

```csv
device,timestamp,reading_kwh
```

- `device`：设备标识，去除首尾空白后不能为空，区分大小写。
- `timestamp`：ISO8601，秒精度，必须带 `Z` 或 `±HH:MM` 数字时区偏移，须为真实日期（无效日期不会顺延）。
- `reading_kwh`：非负累计读数（kWh），最多三位小数；数值等价的写法视为相同读数。
- 支持标准双引号字段、`""` 转义双引号以及 CRLF/LF 换行。

读数身份 = 设备标识 + 实际时刻（不同偏移表示同一时刻视为同一身份）。相同身份相同数值为重复（跳过并计数）；相同身份不同数值为冲突，整批拒绝并指出行号与原因，不留下部分数据。允许乱序文件与补导历史读数。

## 查询筛选

```sh
node app.ts readings --device <id> --from <iso> --to <iso>
```

- 时间边界须带时区；起点含、终点不含；省略表示不限；起点不早于终点时拒绝查询。
- 结果按设备及实际时刻排序，显示时间、累计读数、与同设备紧邻前驱构成的区间及消耗，并按设备汇总有效消耗。
- 前驱取自完整已存时序（可在范围外）；无前驱时标明无法计算；读数下降显示下降异常且不计入汇总。

## 数据位置

默认 `<用户主目录>/.meterwatch/readings.json`。可用环境变量 `METERWATCH_DATA_DIR`
或参数 `--data-dir <dir>` 指定数据目录（命令行参数优先）。存储损坏或不可读时
命令失败，不会当作空库覆盖。
